# The Depths

A work-in-progress side-scrolling dungeon crawler. One HTML file, no build step.

- A generated world of 36 x 24 screens in eight zones, with chains, ledges, shops, keys and locked doors.
- Keyboard (arrows or WASD, Z or Space to jump, X to swing the flail), mouse, game controller and touch controls (iPad, phone).
- The revision number is shown in the bottom-left corner of the game.

All art is original. This is a hobby project and is not affiliated with any game publisher.
